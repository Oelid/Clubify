# Clubify

SaaS multi-clubs de gestion de clubs de sport, conçu d'abord pour un club pour enfants (3 à 14 ans) au Maroc.

Le cœur du produit : l'inscription d'un enfant dans un groupe récurrent pour une saison, payée au comptoir en espèces, chèque ou virement. La réservation à la séance est un cas secondaire (cours privés, carnets, essais, rattrapages, camp).

## État du projet

Cadrage. Aucune technologie choisie, aucun code écrit. Le cahier des charges (version 1.1) est figé.
